Systems and algorithms

Five repositories kept public because the trajectory is the interesting part: a shell, two game-AI agents, an unfinished reinforcement-learning experiment, and the practice archive underneath all of it.

A Unix shell, written from scratch

customBash is a shell in C++ — parse a line, fork, exec, wire up pipes and redirection, and hold onto the job so you can wait on it. It has cd and exit as builtins, which it has to, because a child process cannot change its parent's working directory. That single constraint is the reason every shell on earth has builtins, and you do not really feel it until you write one.

Writing a shell is the fastest way to stop treating fork and exec as trivia. You cannot get a pipeline working without understanding that the file descriptor table survives the exec, and that nothing else does.

Two agents, two algorithms, one room

ai-cops-and-robbers is a pursuit-evasion game in C++ and SFML. A cop and a robber move around the same map running different search algorithms, which turns the project into a comparison rather than a demo: same world, same constraints, and you get to watch which strategy actually wins.

It came out of NC State's game-AI course, where the broader version of this — steering, pathfinding and a decision tree stacked on top of each other — is written up in the coursework notes.

An unfinished Deep Q-Network, kept unfinished

ai-arcade-games is Snake rebuilt as a reinforcement-learning environment, plus the scaffolding for an agent that learns to play it. The environment is complete — play_step(action) returns (reward, done, score) — and so is the training loop: state encoding, replay memory, epsilon-greedy action selection. The network itself was never written. Agent.model and Agent.trainer are still None.

It is published that way on purpose. The part worth reading is the state encoding: the agent never sees the board. It sees eleven booleans — danger straight, danger right, danger left, the four direction flags, and where the food is relative to the head. Feeding a network that instead of raw pixels is the difference between training on a laptop and needing a cluster, and it is a decision you make before you write a single layer.

Rewards are deliberately sparse: +10 for food, -10 for dying, 0 the rest of the time.

The practice archive

leetcode-archive holds 221 problems solved in Python between May 2023 and September 2024 — the first sustained run, kept as a record and not cleaned up afterwards. Some of the solutions are not optimal. They are as I first wrote them.

It is heavier on the patterns that actually repeat: two pointers, sliding window, monotonic stack, BFS and DFS on trees and grids, heaps, dynamic programming. The design problems are the ones worth reading if you only read a few — LRU cache, min stack, underground system, browser history.

What replaced it is LC Bot, where an Obsidian note is the source of truth and the repository is generated from it, with spaced repetition scheduling the reviews. The archive is what that workflow was built to fix.

Where it started

first-code is the first C++ I ever wrote, in 2020, unedited. The board game Trouble across six numbered attempts. An expression tree across four. K-ary and binary trees by hand, because the STL was not allowed. It is the bottom of the graph, and it stays up for the same reason the Snake agent does.

There is one line in it I will not fix — an #include pointing at an absolute path on a Windows drive letter, on a machine I no longer own. It compiled on exactly one computer on earth and at the time I thought that was fine.
